# Как загрузить проект в GitHub

## 1. Подготовь файлы

В репозитории должны быть следующие файлы:

- `README.md` — основное описание проекта на английском; GitHub автоматически показывает его на главной странице репозитория.
- `README_RU.md` — русская версия описания.
- `01-main-menu.png` — главное меню.
- `02-staff-roles.png` — меню персонала.
- `03-medicine-catalog.png` — каталог.
- `04-shopping-cart.png` — форма корзины.

## 2. Создай репозиторий

1. Зайди на https://github.com и войди в аккаунт.
2. Нажми знак `+` в правом верхнем углу и выбери **New repository**.
3. Название: `medexpert-access-portfolio`.
4. Краткое описание: `Educational Microsoft Access pharmacy database application with forms, queries, and checkout receipt workflow.`
5. Выбери **Public**, если проект можно показывать всем и в файлах нет личных или конфиденциальных данных.
6. Поставь галочку **Add a README file** можно не ставить, потому что свой `README.md` уже подготовлен.
7. Нажми **Create repository**.

## 3. Загрузи подготовленные файлы

1. В новом репозитории выбери **Add file → Upload files**.
2. Распакуй архив с файлами на компьютере.
3. Перетащи в окно загрузки `README.md`, `README_RU.md` и четыре PNG-файла. Загружай сами файлы из папки, а не ZIP-архив целиком.
4. Внизу страницы в поле commit message введи `Add MedExpert Access portfolio project`.
5. Нажми **Commit changes**.

Если GitHub уже создал `README.md`, сначала открой его и замени его содержимое своим английским README, либо удали/переименуй первоначальный файл перед загрузкой, чтобы не было конфликта имён.

## 4. Проверь результат

- На главной странице сразу видны название и английское описание.
- Все четыре изображения отображаются внутри README.
- Открой `README_RU.md` и проверь русский текст.
- Скопируй ссылку на репозиторий — это ссылка на первый проект в портфолио.

## 5. Пока не загружай базу `.accdb`

Не добавляй исходный файл базы данных на публику, пока не проверишь все таблицы на наличие личных данных, паролей, служебной информации или иных чувствительных сведений. Для первой версии портфолио достаточно README и скриншотов. Если позднее захочешь приложить демонстрационную базу, сначала сделай копию, оставь только вымышленные данные и проверь, что файл не содержит конфиденциальных сведений.

## 6. Что улучшить после первой загрузки

- заменить скриншот меню персонала на снимок без выделенного текста;
- сделать скриншот каталога без выделения текста в поле названия;
- добавить снимок заполненной корзины;
- добавить снимок сформированного чека;
- добавить схему связей таблиц Access;
- добавить 2–3 примера запросов и кратко объяснить, что каждый делает.
